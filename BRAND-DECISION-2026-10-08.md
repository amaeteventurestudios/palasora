# Palavva brand decision: Midnight + Tangerine

**Decision date:** 2026-10-08  
**Status:** Founder approved. Implementation required.

The founder rejected the prior forest-green identity and selected **Midnight + Tangerine**. This is a superseding **visual** decision, not a revision to the editorial, architecture, privacy, model-hosting, sponsorship, deployment, or public-launch policies.

| Color | Value | Usage |
| --- | --- | --- |
| Midnight | `#1B2030` | Header, footer, headlines, dark editorial panels, Command Center sidebar |
| Tangerine | `#E85E31` | Brand dot, active tabs, expressive accents |
| Warm Gold | `#F8C45C` | Controlled historical and highlight details |
| Ivory | `#F8F5F0` | Reading background |
| Dark Tangerine accessibility variant | `#C34218` | White-label primary controls and contrast-safe links |

## Implementation and precedence

This note, `05-UI-DESIGN-SYSTEM.md`, `04-UX-SCREEN-SPECIFICATIONS.md`, `15-VISUAL-ASSET-BRIEFS.md` and `19-AUTONOMOUS-BUILD-PROMPT.md` supersede **only** earlier forest-green sketches in the archived `00-PROJECT-HANDOFF.md`. That historical source file stays unaltered. All six starter SVG/PNG sets in `assets/` are regenerated in the new direction.

The website is a **modern African digital newsroom with conversational/social discovery**, not a cinematic image hero, institutional media portal or generic white card dashboard. Show real readable content immediately, with a compact Midnight masthead, clear country/industry navigation, a prominent but bounded featured conversation, compact companion stories, and accessible community interactions. Keep sponsors and AI contributions properly identified.

No Mac files or live Oracle/Hetzner systems were remotely changed by this package. The local replacement ZIP requires a copy into the founder’s Mac `Projects/palavva` directory.
