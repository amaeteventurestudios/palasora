# Phase 2 result: news, evidence and AI editorial

**Built:** source registry with rights gate; SSRF-safe fetcher; defusedxml RSS/Atom/RDF parser; normalization, dedup (GUID, content hash), clustering with match explanations; durable SQLite queue (leases, retries, dead letters, idempotency, daily per-tenant budgets); Ollama provider (concurrency 1, schema-constrained JSON, one shorter retry), deterministic fixture provider, disabled cloud adapters; curator → researcher → writer → deterministic validator → 0–3 roles; Time Lens returns `NO_VERIFIED_COMPARISON` (no archive records exist yet); FTS5 search; kill switches.
**Real run:** SAnews.gov.za (rights reviewed, provisional): 10 real items → 10 clusters → **2 drafts in review**, 8 held (no verifiable claims or writer abstained). **74 real Qwen calls**: curator 12–36 s (mean 17.7); researcher succeeded 11 times (mean 23 s) and abstained 20 times; writer succeeded 3 times (mean 21 s). Totals: about 46k input / 14k output tokens. **Finding:** the 4B model is very conservative with headline+excerpt evidence. Recommend richer permitted excerpts or a larger local model before relying on volume.
**Tests:** pytest 39 (unit + integration on an isolated PocketBase) and 4 real-Qwen tests (structured output, role abstention, prompt injection, outage).
